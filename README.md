# shuhao-startup

## 🧾 Overview
**shuhao-startup** is a solo-developed startup-style project designed to simulate a scalable web platform. This application focuses on user experience, error resilience, and route protection. It serves as a showcase of practical engineering patterns including modular components, RESTful API design, and clean architecture.

## 👨‍💻 Built By
Shuhao Ruan – Developer with real-world full-stack project experience, including building production-quality features during Chuwa training and personal initiatives.

## 🔧 Tech Stack
- Frontend: React, Vite, React Router
- Backend: Express.js, Node.js
- Database: MongoDB
- Authentication: JWT-based auth flow
- Dev Tools: GitHub, Postman, VSCode

## 💡 Features
- ✏️ Full-stack user flow from sign-up to login
- 🔐 Auth token storage and protected routes
- 📄 Form validation and user feedback
- 🧱 Clean folder structure with scalable architecture
